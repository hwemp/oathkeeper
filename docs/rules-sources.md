# Rules sources

The initial calculation subset uses the 2014 rules represented in the
[System Reference Document 5.1](https://www.dndbeyond.com/attachments/39j2li89/SRD5.1-CCBY4.0License.pdf),
published under CC BY 4.0. Its first page supplies permission and attribution
terms. This is the source for the implemented subset, not permission to reproduce
the entire 2014 Player's Handbook.

Implemented references (printed SRD page numbers):

- Character advancement / proficiency bonus: page 56, levels 1–20.
- Ability modifiers: page 76; subtract 10, divide by two, round down.
- Saving throws: page 82; ability modifier plus proficiency when selected.
- Initiative: page 90; Dexterity check, with manually entered feature bonuses.

The interface explanations are original summaries. The calculations implement
these selected rules. Class/race features, skills, spells, equipment, and other
book content are not yet automated or reproduced. Manual adjustments are an
app feature and must be justified by the user's notes, not inferred as a rule.
